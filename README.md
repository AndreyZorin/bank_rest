# Система управления банковскими картами

## Функции

### Администратор

- Управление пользователями (создание, обновление, удаление, просмотр через поиск с фильтрацией, сортировкой и пагинацией.)
- Управление картами (создание, обновление, удаление, просмотр через поиск с фильтрацией, сортировкой и пагинацией.)

### Пользователь

- Переводы между своими картами
- Просмотр баланса
- Запрос на блокировку (установка флага на блокировку без фактической блокировки)

### Начало работы

Через  docker-compose.yml запускается контейнер с базой данных. В базу данных при старте приложения помещается дефолтный администратор с ником 'superman' и паролем 'superpassword'.
Получение токена доступа происходит через ендпоинт '/api/v1/auth/login'. Остальные ендпоинты описаны в Swagger '/swagger-ui/index.html' и в файле ./docs/openapi.yaml. 

## Технологии

Java 24, Sprung Boot 3.5.6, Spring Web, Swagger (OpenAPI), Spring Data JPA, PostgreSQL, Liquibase, Spring Security, JWT, Lombok, Mapstruct.
